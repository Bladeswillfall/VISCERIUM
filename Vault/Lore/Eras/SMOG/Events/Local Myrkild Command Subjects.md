## Summary

Artificial symbiosis produced subjects able to impose limited influence on nearby Myrkild behaviour.

## Context and Course

Earlier trials had progressed from sensing nearby activity to provoking hesitation, attraction, withdrawal or redirected aggression. A true Nadir remained vastly beyond this capability.

## Consequences and Memory

The subjects offered a defensive tool while creating a new danger: using the Myrkild network also risked being noticed, overridden or used as a route back into the subject.
