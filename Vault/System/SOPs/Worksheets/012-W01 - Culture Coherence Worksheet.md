## 2. Trace defining elements backwards

Choose three to five elements that strongly affect identity or behaviour.

For each element, trace the chain backwards:

| Question | Answer |
| --- | --- |
| What exists now? |  |
| What repeated action created or preserved it? |  |
| What obstacle made that action useful or necessary? |  |
| What need, desire, fear, or pressure sat beneath the obstacle? |  |
| What bedrock supports the chain: environment, resource, historical event, institution, belief, or human need? |  |

Repeat this block for each selected element.
