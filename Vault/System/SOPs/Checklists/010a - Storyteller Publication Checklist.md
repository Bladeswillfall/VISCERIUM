# Storyteller Publication Checklist

> **Parent SOP:** [[Storyteller View SOP]]

## Boundaries

- [ ] The note contains one start marker and one end marker.
- [ ] The markers appear in the correct order.
- [ ] All Storyteller content sits between the markers.
- [ ] Creator-only secrets remain private unless public disclosure is deliberate.

## Content

- [ ] The section gives practical scene, encounter, journey, location, or plot guidance.
- [ ] Every world fact is supported by Lore or another canonical source.
- [ ] The section does not infer negative canon from missing information.
- [ ] The section does not duplicate Lore only to appear complete.
- [ ] Shared guidance remains fiction-first and system-agnostic.

## Presentation and validation

- [ ] Headings match the available material rather than a mandatory schema.
- [ ] Images, tables, callouts, links, and layout syntax render correctly.
- [ ] The Lore and Storyteller views do not contradict one another.
- [ ] The public switch appears only when useful Storyteller content exists.
- [ ] The public build completes without marker errors.

## Decision

- [ ] **Publication ready**
- [ ] **Not ready** - blocking reason recorded.
